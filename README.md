# LinkComment AI

**Every post deserves a relevant comment.**

LinkComment AI is a Chrome Extension designed to help LinkedIn users generate meaningful, relevant, and natural English comments for LinkedIn posts.

Instead of spending time thinking about what to write, users can generate a comment, review it, and copy it with a single click.

## ✨ Features

- **Post Understanding:** Reads the visible LinkedIn post text and context.
- **AI-Powered Comments:** Generates relevant English comments based on the post's topic and tone.
- **One-Click Generation:** Generate a comment directly from the extension interface.
- **Copy Comment:** Easily copy the generated comment.
- **User-Controlled Engagement:** Comments are never automatically published.

## 🛠️ Tech Stack

- JavaScript
- HTML5
- CSS3
- Chrome Extension Manifest V3
- AI Integration

## 🚀 How It Works

1. Install the extension in Chrome.
2. Open LinkedIn and navigate to a post.
3. Open LinkComment AI.
4. Click **Generate Comment**.
5. Review the generated comment.
6. Click **Copy Comment**.
7. Paste and publish the comment manually on LinkedIn.

## 🔐 Privacy & User Control

LinkComment AI is designed to keep users in control of their LinkedIn engagement.

- It does not automatically publish comments.
- Users review generated comments before posting.
- Generated comments are intended to assist users, not replace their own judgment.

## 📌 Project Goal

The goal of LinkComment AI is to make professional networking easier by helping users participate in meaningful conversations on LinkedIn.
